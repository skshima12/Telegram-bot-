Common Errors

API_ID_INVALID → my.telegram.org से API ID/Hash दोबारा check करें.

PHONE_CODE_INVALID → नया login code लें.

SESSION_PASSWORD_NEEDED → 2FA password डालें.

CHAT_WRITE_FORBIDDEN / CHAT_SEND_POLL_FORBIDDEN → अपने account को उस group में poll भेजने की अनुमति होनी चाहिए.

Flood / rate limit → delay बढ़ाएँ; Telegram limits को bypass न करें.
